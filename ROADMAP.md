# Roadmap after 1.0

The 1.0 release includes a self-contained Windows installer, multiple job tabs, SVG/DXF/raster/STEP planar-face import, shared presets, numeric calculators, vector editing, SVGnest nesting, sheet previews, corrected tangent-tab clearances, simulation, sheet/batch posting and a 48-tool MCP server.

## Planned work

- Trusted Windows code signing and clean-VM installer/upgrade testing across supported architectures.
- Recoverable job autosaves and recent-file lists.
- Remnant inventory and irregular stock editing.
- More geometry repair, source-layer preservation, boolean operations and constrained vector editing.
- Broader STEP body/face selection and additional real-world import fixtures.
- Continued process-profile and firmware comparisons, followed by physical machine validation.
- More nesting benchmarks and search improvements.

Water-only cutting and engraving are not implemented. Physical process validation remains machine-specific. This project is independent of WAZER and does not claim manufacturer approval.

Earlier plans and capture details are retained in [the archived development plan](docs/ROADMAP-HISTORY.md).
