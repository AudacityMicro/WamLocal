# Wam Local 1.0.0

The first full Windows release brings the complete job workflow into one desktop application for WAZER Desktop and Pro.

## Install

Download **Wam-Local-Setup.exe** and run it. The one-click installer selects x64, ARM64 or x86 automatically, includes the runtime and creates shortcuts. No Node.js, npm, Python or separate setup is required. Windows 10/11 only; this unsigned release may trigger Windows security approval. Runtime testing was performed on x64 Windows.

## Included

- Job tabs and self-contained WAM job files, with shared presets and sticky machine settings.
- SVG, DXF, raster and STEP planar-face import, basic vector editing and part thumbnails.
- SVGnest nesting, sheet previews, selection tools and WCS origins based on sheets or placed-part bounds.
- Editable kerf, stock allowance, tabs, leads and overlap. Tangent tab gaps include arc/kerf clearance; small-hole tab leads do not meet at a common centroid.
- Numeric calculators and unit conversion throughout the editor, plus explicit preset saving.
- Sheet/batch G-code posting, time/abrasive/cost reports, zoomable simulation and the bundled 48-tool MCP server.
- Optional manual GitHub updates.

Save and close older running copies before installing. Repost older cut files to use the tangent-tab corrections. Presets and saved jobs are preserved. This is independent CAM software; physical process/firmware validation remains machine-specific, and water-only cutting is not included.
